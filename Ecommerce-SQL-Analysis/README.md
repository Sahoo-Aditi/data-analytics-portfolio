# E-commerce Sales Data Analysis (SQL Project)

## Project Overview
Analyzed an e-commerce dataset using SQL to identify customer behavior, product demand, and sales trends.

## Tools Used
- MySQL
- SQL (Joins, CTEs, Window Functions, Aggregations)

## Key Business Insights
- Top customer cities: Delhi, Chennai, Jaipur
- Electronics category attracted 79 unique customers
- Laptop 15 Pro generated ₹7,560,000 revenue (highest product revenue)
- Identified top 5 high-demand products based on sales frequency
- Performed month-on-month sales growth analysis using SQL window functions
- Identified low-demand products purchased by <40% customers, indicating optimization opportunities

## SQL Concepts Used
- GROUP BY & Aggregations
- JOIN operations
- Common Table Expressions (CTE)
- Window Functions (LAG)
- Subqueries
